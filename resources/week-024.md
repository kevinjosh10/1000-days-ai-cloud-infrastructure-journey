# Week 24 Resources: Docker & Containers

## 📚 Official Documentation
- **Docker Documentation:** [docs.docker.com](https://docs.docker.com/)
- **Dockerfile Reference:** [docs.docker.com/engine/reference/builder/](https://docs.docker.com/engine/reference/builder/)
- **Docker Compose:** [docs.docker.com/compose/](https://docs.docker.com/compose/)
- **Trivy Vulnerability Scanner:** [aquasecurity.github.io/trivy](https://aquasecurity.github.io/trivy/)
- **LocalStack:** [docs.localstack.cloud](https://docs.localstack.cloud/)
- **Amazon ECR (Elastic Container Registry):** [aws.amazon.com/ecr/](https://aws.amazon.com/ecr/)

## 📖 Recommended Reading
- **Docker Deep Dive by Nigel Poulton:** The definitive book for understanding Docker internals (Namespaces, Cgroups, UnionFS).
- **12-Factor App Methodology:** [12factor.net](https://12factor.net/) (Essential architectural principles for building cloud-native, containerized applications).

## 🛠️ Tools Installed
- **Docker Desktop / Docker Engine:** The core container runtime.
- **Trivy CLI:** `brew install trivy` (For scanning images locally).
- **AWS CLI (Updated):** Used for `aws ecr get-login-password` to authenticate Docker with AWS ECR.
