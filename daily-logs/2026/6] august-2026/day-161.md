### 3️⃣ Architected the Ultimate CI/CD Pipeline

Designed the automated enforcement mechanisms for GitHub Actions.

Workflow designed:
1. `terraform fmt -check` (Instantly fails if code is ugly)
2. `terraform validate` (Fails if module syntax is broken)
3. `conftest test` (Fails if security policies are violated)
4. `go test` (Runs Terratest to mathematically prove the infrastructure works)
5. `terragrunt run-all apply` (Executes only when merged to `main`)

Understood:
- True engineering means shifting left: finding and breaking bad code before it ever reaches production.
