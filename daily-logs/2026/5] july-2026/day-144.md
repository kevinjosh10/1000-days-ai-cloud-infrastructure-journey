## 🛠️ Execution & Architecture

### 1️⃣ Conceptualized The `count` Meta-Argument
Designed and deployed Replacing copy-pasted blocks with a dynamic iteration loop.

```text
count = 3 -> Creates 3 identical EC2 instances automatically
```

### 2️⃣ Conceptualized Index Interpolation
Designed and deployed Naming resources uniquely based on their loop iteration position.

```text
Name = 'web-${count.index}' -> Outputs web-0, web-1, web-2
```

### 3️⃣ Conceptualized Splat Expressions
Designed and deployed Extracting all attributes from a looped resource simultaneously.

```text
value = aws_instance.web[*].public_ip -> Returns a list of all IPs
```

### 4️⃣ Conceptualized The Count Flaw (Resource Shift)
Designed and deployed Understanding why `count` is dangerous for stateful or named resources.

```text
Remove index [1] -> Terraform shifts index [2] to [1] -> Unintended Destruction
```
