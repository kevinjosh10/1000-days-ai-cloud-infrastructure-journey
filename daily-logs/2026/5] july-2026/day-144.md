# Day 144 – Terraform Expressions, Loops & Conditionals

**Date:** 23 July 2026
**Duration:** ~3 Hours
**Focus:** HCL Logic, Meta-Arguments (`count`, `for_each`), Splat Expressions (`[*]`), Collection Iteration (`for`), and Environment-Based Conditionals (`? :`)

---

## 🎯 Objective

Implement programmatic logic within declarative Terraform configurations to dynamically provision fleets of resources and handle multi-environment architectural differences.

Learn:

- The `count` Meta-Argument and `count.index` interpolation
- Splat Expressions for array extrapolation (`[*]`)
- The `for_each` Meta-Argument vs `count` for named resources
- Collection transformations using `for` expressions
- Ternary Conditional logic (`condition ? true_val : false_val`)
- Dynamic Resource attachment based on environment logic
- Avoiding the 'Resource Shift' destruction trap of `count`

Practice:

- Mastering The `count` Meta-Argument and `count.index` interpolation via local `main.tf` experimentation
- Mastering Splat Expressions for array extrapolation (`[*]`) via local `main.tf` experimentation
- Mastering The `for_each` Meta-Argument vs `count` for named resources via local `main.tf` experimentation
- Mastering Collection transformations using `for` expressions via local `main.tf` experimentation
- Mastering Ternary Conditional logic (`condition ? true_val : false_val`) via local `main.tf` experimentation
- Mastering Dynamic Resource attachment based on environment logic via local `main.tf` experimentation
- Mastering Avoiding the 'Resource Shift' destruction trap of `count` via local `main.tf` experimentation
- Provisioning multiple IAM users via `for_each` and a `toset()` function
- Scaling an EC2 web cluster dynamically via the `count` meta-argument
- Conditionally provisioning an EBS volume ONLY in a simulated 'prod' environment
