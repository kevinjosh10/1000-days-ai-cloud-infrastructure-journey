## 🛠️ Execution & Architecture

### 1️⃣ Conceptualized Workspace Initialization
Creating a new logical environment without moving directories or duplicating code.

```text
`terraform workspace new staging` -> Instantly branches the state file
```

### 2️⃣ Conceptualized The Default Workspace
Understanding that every Terraform project silently starts in a workspace called 'default'.

```text
The default state file lives at the root of the S3 key; custom workspaces live in `env:/`
```

### 3️⃣ Conceptualized Dynamic Code Interpolation
Using the reserved `terraform.workspace` variable to make HCL context-aware.

```text
tags = { Name = '${terraform.workspace}-vpc' } -> Results in 'staging-vpc'
```

### 4️⃣ Conceptualized Conditional Infrastructure Sizing
Using ternary operators to map hardware requirements to the active workspace.

```text
instance_type = terraform.workspace == 'prod' ? 'm5.large' : 't3.micro'
```
