# Day 152 – Project 1: Complete AWS Infrastructure

**Date:** 31 July 2026
**Duration:** ~6 Hours
**Focus:** Orchestrating a Complete 3-Tier Production Architecture (VPC, RDS, ALB, ASG) via Terraform Module Composition.

---

## 🎯 Objective

Execute the ultimate Phase 2 capstone project by engineering a highly available, secure, multi-AZ AWS infrastructure stack entirely from scratch using completely decoupled Terraform modules.

Learn:

- Architecting complex AWS Relational Database Service (RDS) modules
- Configuring Application Load Balancer (ALB) Target Groups and Listeners dynamically
- Managing Security Group chaining (Internet -> ALB -> App -> RDS)
- Module Composition: Passing outputs from networking to compute to database
- Orchestrating implicit dependency graphs across 20+ resources
- Verifying live HTTP endpoints against declarative configuration code
- The absolute necessity of immediate `terraform destroy` after massive testing

Practice:

- Executing Architecting complex AWS Relational Database Service (RDS) modules in local environment
- Executing Configuring Application Load Balancer (ALB) Target Groups and Listeners dynamically in local environment

- Executing Orchestrating implicit dependency graphs across 20+ resources in local environment
- Executing Verifying live HTTP endpoints against declarative configuration code in local environment
- Executing The absolute necessity of immediate `terraform destroy` after massive testing in local environment
