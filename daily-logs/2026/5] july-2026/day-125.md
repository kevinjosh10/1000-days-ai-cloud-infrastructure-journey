### 🌐 Networking & VPC Refresher
- **Transit Gateway vs. VPC Peering**: Transit Gateway is for hub-and-spoke topologies to connect multiple VPCs and on-prem networks, whereas VPC Peering is strictly for 1-to-1 non-transitive routing.
- **Endpoints**: Gateway Endpoints are *exclusively* for S3 and DynamoDB. Everything else uses Interface Endpoints (AWS PrivateLink).

### 🗄️ Database & Storage Selection
- **RDS vs. Aurora vs. DynamoDB**:
  - *RDS*: Standard relational database. Multi-AZ is for high availability/DR, and Read Replicas are strictly for read performance scaling.
  - *Aurora*: Cloud-native relational database. Storage scales automatically. Serverless is for unpredictable workloads; Global Database is for cross-region DR with sub-second latency.
  - *DynamoDB*: Non-relational key-value store with single-digit ms latency. Use DAX when "microsecond latency" is mentioned.

### 🔑 Cheat Sheet Keyword Associations
- **Decouple** ➔ SQS
- **Pub/Sub or Multiple subscribers** ➔ SNS
- **Real-time streaming / Big Data ingestion** ➔ Kinesis
- **NFS / Linux multiple EC2 access** ➔ EFS
- **Windows file server / SMB** ➔ FSx for Windows
- **High-performance computing (HPC) / Lustre** ➔ FSx for Lustre
