## 🛠️ Execution & Architecture

### 1️⃣ Engineered Dockerfile Basics
Explored and executed Defining infrastructure and application requirements in a single text blueprint.

```text
Dockerfile -> Set Instructions -> Defines App Dependencies
```

### 2️⃣ Engineered The FROM Instruction
Explored and executed Inheriting an official, pre-configured base image to save setup time.

```text
FROM python:3.12-slim -> Pulls lightweight Debian OS + Python binary
```

### 3️⃣ Engineered The WORKDIR Instruction
Explored and executed Setting the execution context directory inside the container.

```text
WORKDIR /app -> Automatically cd's into /app for all following commands
```

### 4️⃣ Engineered The COPY Instruction
Explored and executed Transferring local application code into the container filesystem.

```text
COPY . /app -> Moves local python scripts into the isolated environment
```
