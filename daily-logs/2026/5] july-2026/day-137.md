# Day 137 – Dockerfile Creation & Volumes

**Date:** 16 July 2026
**Duration:** ~3 Hours
**Focus:** Custom Image Building, Dockerfile Syntax (FROM, WORKDIR, COPY, CMD), Data Persistence with Volumes, Multi-Container Orchestration (Docker Compose Preview)

---

## 🎯 Objective

Advance from running pre-built containers to engineering custom immutable images using Dockerfiles, and implement local data persistence to overcome container ephemerality.

Learn:

- Dockerfile Anatomy and Instruction Hierarchy
- The `FROM` Directive (Base Images)
- The `COPY` and `WORKDIR` Directives
- The `CMD` and `ENTRYPOINT` Directives
- Image Building (`docker build -t`)
- Data Persistence (Docker Volumes & Bind Mounts)
- The `docker-compose.yml` Structure (YAML)
- Multi-Container Networking via Compose

Practice:

- Implementing Dockerfile Anatomy and Instruction Hierarchy in local development
- Implementing The `FROM` Directive (Base Images) in local development
- Implementing The `COPY` and `WORKDIR` Directives in local development
- Implementing The `CMD` and `ENTRYPOINT` Directives in local development
- Implementing Image Building (`docker build -t`) in local development
- Implementing Data Persistence (Docker Volumes & Bind Mounts) in local development
- Implementing The `docker-compose.yml` Structure (YAML) in local development
- Implementing Multi-Container Networking via Compose in local development
- Writing a custom Python `Dockerfile` from scratch
- Executing `docker build -t my-first-app .`
- Mapping a host directory to a container using `-v`
