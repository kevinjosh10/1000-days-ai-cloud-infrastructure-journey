## 🛠️ Execution & Architecture

### 1️⃣ Engineered Module Architecture
Architected and implemented Understanding that any directory with `.tf` files is inherently a module.

```text
The folder where `terraform apply` is executed becomes the Root Module
```

### 2️⃣ Engineered The Monolith Anti-Pattern
Architected and implemented Realizing that writing 1,000 lines of HCL in a single `main.tf` destroys readability and scaling.

```text
Code must be decoupled. VPC code shouldn't mix with IAM code.
```

### 3️⃣ Engineered Child Module Creation
Architected and implemented Scaffolding the internal directory structure for reusable building blocks.

```text
mkdir -p modules/security_group -> touch main.tf variables.tf outputs.tf
```

### 4️⃣ Engineered Module Inputs (Variables)
Architected and implemented Defining the schema for the arguments the root module must provide.

```text
variable 'vpc_id' -> variable 'sg_name' -> variable 'ingress_ports'
```
