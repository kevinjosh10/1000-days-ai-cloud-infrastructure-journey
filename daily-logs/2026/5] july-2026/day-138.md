## 🛠️ Execution & Architecture

### 1️⃣ Conceptualized The Orchestration Problem
Understanding why running raw Docker containers across 50 servers is a nightmare.

```text
Crash at 3 AM -> No auto-restart -> Downtime -> K8s solves this via Self-Healing
```

### 2️⃣ Conceptualized Kubernetes (K8s)
The open-source orchestration engine acting as the brain for massive container fleets.

```text
Monitors State -> Desired State vs Actual State -> Reconciles Differences
```

### 3️⃣ Conceptualized Minikube Initialization
Bootstrapping a lightweight, local Kubernetes cluster for testing.

```text
`minikube start` -> Downloads ISO -> Creates VM -> Boots Control Plane
```

### 4️⃣ Conceptualized The `kubectl` CLI
The primary interface for communicating with the Kubernetes API server.

```text
`kubectl version` -> Confirms client can talk to the cluster API
```
