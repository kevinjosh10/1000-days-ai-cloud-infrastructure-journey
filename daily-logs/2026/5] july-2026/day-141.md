# Day 141 – HCL Syntax & Terraform Fundamentals

**Date:** 20 July 2026
**Duration:** ~3 Hours
**Focus:** HCL Block Syntax, Terraform Workflow (init/plan/apply), S3 Bucket Provisioning, State File Management (`terraform.tfstate`), Validation & Formatting Tools

---

## 🎯 Objective

Execute the first real Infrastructure as Code deployment by mastering HashiCorp Configuration Language (HCL) syntax and the core Terraform lifecycle workflow.

Learn:

- HCL Block Types (`resource`, `provider`, `variable`, `output`, `data`)
- The Terraform Lifecycle (`init`, `plan`, `apply`, `destroy`)
- Declarative vs Imperative provisioning logic
- The Terraform State File (`terraform.tfstate`) and State Locking
- `.gitignore` requirements for sensitive state files
- Code hygiene with `terraform fmt` and `terraform validate`
- Resource chaining and implicit dependencies in HCL

Practice:

- Applying HCL Block Types (`resource`, `provider`, `variable`, `output`, `data`) concepts in local environment
- Applying The Terraform Lifecycle (`init`, `plan`, `apply`, `destroy`) concepts in local environment
- Applying Declarative vs Imperative provisioning logic concepts in local environment
- Applying The Terraform State File (`terraform.tfstate`) and State Locking concepts in local environment
- Applying `.gitignore` requirements for sensitive state files concepts in local environment
- Applying Code hygiene with `terraform fmt` and `terraform validate` concepts in local environment
- Applying Resource chaining and implicit dependencies in HCL concepts in local environment
- Authoring `main.tf` to provision an encrypted, versioned AWS S3 bucket
- Executing a dry-run via `terraform plan`
- Creating `.gitignore` to prevent secret leakage
