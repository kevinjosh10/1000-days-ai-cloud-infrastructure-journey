## 🛠️ Execution & Architecture

Implemented and tested Learning the structure of HashiCorp's declarative language.

```text

```

### 2️⃣ Executed Provider Declaration
Implemented and tested Configuring the AWS API plugin and binding the IAM credentials.

```text
provider "aws" { region = "us-east-1" profile = "terraform" }
```

### 3️⃣ Executed Resource Definition
Implemented and tested Instructing Terraform to create physical cloud infrastructure.

```text

```

### 4️⃣ Executed Implicit Dependencies
Implemented and tested Linking resources together by referencing exported attributes.

```text
bucket = aws_s3_bucket.my_first_bucket.id -> Terraform knows to build the bucket first
```
