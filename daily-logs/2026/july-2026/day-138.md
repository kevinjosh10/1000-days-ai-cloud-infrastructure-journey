# Day 138 – Kubernetes Preview & Orchestration Concepts

**Date:** 17 July 2026
**Duration:** ~3 Hours
**Focus:** Container Orchestration, `kubectl` & Minikube Installation, Pods vs Containers, Deployments, Services (NodePort), K8s Architecture

---

## 🎯 Objective

Introduce the foundational concepts of Kubernetes (K8s) to understand how containerized applications are scheduled, scaled, and maintained in production environments.

Learn:

- The Necessity of Container Orchestration
- Kubernetes Control Plane vs Worker Nodes
- Minikube (Local Single-Node Clusters)
- The `kubectl` Command Line Interface
- Pods (The Smallest Deployable Unit)
- Deployments (State Controllers)
- Services (Network Exposure & Load Balancing)
- Self-Healing and Auto-Scaling Concepts

Practice:

- Implementing The Necessity of Container Orchestration via local Minikube
- Implementing Kubernetes Control Plane vs Worker Nodes via local Minikube
- Implementing Minikube (Local Single-Node Clusters) via local Minikube
- Implementing The `kubectl` Command Line Interface via local Minikube
- Implementing Pods (The Smallest Deployable Unit) via local Minikube
- Implementing Deployments (State Controllers) via local Minikube
- Implementing Services (Network Exposure & Load Balancing) via local Minikube
- Implementing Self-Healing and Auto-Scaling Concepts via local Minikube
- Installing `kubectl` and initiating `minikube start`
- Creating an Nginx deployment and exposing it via NodePort
- Observing the Pod lifecycle using `kubectl describe pod`
