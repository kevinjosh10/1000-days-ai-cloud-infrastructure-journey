## 🧠 What I Learned Today

### ⏳ Time & Exam Strategy
- **Elimination Technique**: Pay close attention to constraints in the prompt (like "IPv6 outbound only" or "strict message ordering"). This instantly eliminates options like standard SQS or standard Internet Gateways.

### 🌐 Networking & VPC Refresher
- **DynamoDB VPC Endpoints**: Gateway endpoints are ideal for keeping DynamoDB traffic within the AWS network and updating route tables automatically, without traversing the public internet.
- **Egress-Only Internet Gateways**: Required when you want an IPv6-enabled EC2 instance to initiate outbound connections, but prevent inbound IPv6 connections from the internet.
- **DDoS Mitigation**: Attaching multiple Elastic Fabric Adapters (EFA) or using Dedicated Instances does NOT mitigate DDoS attacks. Instead, use Shield, WAF, CloudFront, and ALBs.

### 🗄️ Database & Storage Selection
- **S3 to Glacier**: Use S3 Lifecycle Policies to automatically transition objects. A custom shell script adds unnecessary operational overhead.
- **S3 Cross-Region Replication**: Both the source and destination buckets MUST have versioning enabled for CRR to work.

### 🔑 Cheat Sheet Keyword Associations
- **Ordered Data & No Duplicates** ➔ Kinesis Data Streams
- **IPv6 Outbound Only** ➔ Egress-Only Internet Gateway
- **Spare Compute / Graceful Interruptions** ➔ EC2 Spot Instances
- **Immutable Log Storage** ➔ Glacier Vault Lock

### 🧩 Scenario Questions I Practiced
