# Day 135 – Phase 2 Orientation — Infrastructure as Code Preview

**Date:** 14 July 2026
**Duration:** ~3 Hours
**Focus:** Terraform Installation, HCL Syntax Introduction, IaC Tool Comparison (CloudFormation, CDK, Pulumi), `terraform init` Execution, Provider Documentation Navigation

## 🎯 Objective

Transition into Phase 2 of the 1000-day journey by establishing a foundational understanding of Infrastructure as Code and setting up HashiCorp Terraform.

Learn:

- Infrastructure as Code (IaC) Core Principles
- HashiCorp Terraform vs AWS CloudFormation
- Terraform vs AWS CDK vs Pulumi
- Terraform Provider Configuration (`main.tf`)
- The role of the `.terraform` directory
- The HashiCorp AWS Provider Documentation Registry
- The 'Write -> Plan -> Apply' Mental Model

Practice:

- Investigating Infrastructure as Code (IaC) Core Principles concepts and executing them locally
- Investigating HashiCorp Terraform vs AWS CloudFormation concepts and executing them locally
- Investigating Terraform vs AWS CDK vs Pulumi concepts and executing them locally
- Investigating Terraform Provider Configuration (`main.tf`) concepts and executing them locally
- Investigating The role of the `.terraform` directory concepts and executing them locally
- Investigating The HashiCorp AWS Provider Documentation Registry concepts and executing them locally
- Investigating The 'Write -> Plan -> Apply' Mental Model concepts and executing them locally
- Installing the Terraform CLI binary on the local workstation
- Executing `terraform init` to download the AWS provider plugin
