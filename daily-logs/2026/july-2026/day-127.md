## 🧠 What I Learned Today

### ⏳ Time & Exam Strategy
- **Domain Weighting**: Security is the heaviest domain (30%), followed by Resilient Architectures (26%). If a question is ambiguous, the answer that is more secure or highly available usually wins over the "easiest" to implement.
- **The 90-Second Rule**: If stuck after 90 seconds, pick a gut-feeling answer, flag it, and move forward to prevent time starvation at the end.

### 🌐 Networking & VPC Refresher
- **Egress-Only Internet Gateway**: Used exclusively for IPv6. It allows instances to initiate outbound connections to the internet but prevents the internet from initiating inbound IPv6 connections.
- **Direct Connect (DX)**: Bypasses the public internet entirely to provide consistent, high-bandwidth throughput between an on-premises data center and an AWS VPC. Transit VPC alone cannot do this.

### 🗄️ Database & Storage Selection
- **DynamoDB Gateway Endpoints**: Keeps traffic between the VPC and DynamoDB strictly within the Amazon network (no internet traversal). Unlike Interface Endpoints, this requires updating the Route Table.
- **S3 Origin Access Control (OAC)**: The modern and correct way to restrict an S3 bucket so it can only be accessed via CloudFront. Do NOT use an IAM user for CloudFront.
- **S3 Standard-IA**: It is strictly for data accessed less frequently but requires rapid access. It does NOT automatically move data to cost-effective tiers (that is Intelligent-Tiering).

### 🔑 Cheat Sheet Keyword Associations
- **IPv6 Outbound Only** ➔ Egress-Only Internet Gateway
- **Consistent Network Experience / High Bandwidth** ➔ AWS Direct Connect
- **CloudFront to Private S3** ➔ Origin Access Control (OAC)
- **Programmatic Cost Forecasting** ➔ AWS Cost Explorer API (with pagination)
- **Scale on Specific Metric / Stop Over-provisioning** ➔ Target Tracking Scaling Policy

### 🧩 Scenario Questions I Practiced
- **Scenario**: A GraphQL API deployed in Fargate needs to securely connect to DynamoDB without traversing the public internet. Cross-account backups are required.
  - **Solution**: *Create a DynamoDB gateway endpoint, associate it with the route table, and use AWS Backup for cross-account copying.*
- **Scenario**: Prevent internet from initiating inbound IPv6 connections, but allow instances outbound IPv6 access. Ensure traffic filtering.
  - **Solution**: *Egress-Only Internet Gateway + AWS Network Firewall.*
- **Scenario**: Need to speed up an EC2 instance's loading time for a Windows app without increasing costs.
  - **Solution**: *Enable Hibernation mode on the EC2 instance.*
