# Day 136 – Docker Preview & Container Foundations

**Date:** 15 July 2026
**Duration:** ~3 Hours
**Focus:** Containerization Fundamentals, Docker Desktop Installation, VMs vs Containers, Docker CLI, Nginx/Python Isolated Environments

---

## 🎯 Objective

Establish a foundational understanding of containerization by installing Docker, running isolated web servers and runtime environments, and conceptualizing the differences between containers and virtual machines.

Learn:

- Docker Desktop Installation and Verification
- The Containerization Paradigm (Shared Host OS Kernel)
- Virtual Machines (VMs) vs Containers
- Docker CLI Basics (`docker run`, `docker ps`, `docker stop`)
- Port Mapping and Detached Mode (`-d -p 8080:80`)
- Interactive Terminal Environments (`-it`)
- The Docker Engine Architecture
- Container Lifecycles (Ephemeral environments)

Practice:

- Analyzing Docker Desktop Installation and Verification in local environments
- Analyzing The Containerization Paradigm (Shared Host OS Kernel) in local environments
- Analyzing Virtual Machines (VMs) vs Containers in local environments
- Analyzing Docker CLI Basics (`docker run`, `docker ps`, `docker stop`) in local environments
- Analyzing Port Mapping and Detached Mode (`-d -p 8080:80`) in local environments
- Analyzing Interactive Terminal Environments (`-it`) in local environments
- Analyzing The Docker Engine Architecture in local environments
- Analyzing Container Lifecycles (Ephemeral environments) in local environments
- Executing `docker run hello-world`
- Running a live Nginx web server on localhost:8080
- Spawning an isolated Python 3.12 environment
