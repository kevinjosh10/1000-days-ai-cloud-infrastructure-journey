# Day 148 – Terraform Module Fundamentals

**Date:** 27 July 2026
**Duration:** ~3 Hours
**Focus:** Code Reusability, Root vs Child Modules, Variable Injection, Output Extraction, and the `terraform get` CLI command.

---

## 🎯 Objective

Transition from writing monolithic, single-use Terraform scripts to engineering highly scalable, reusable child modules that act as standard building blocks for enterprise cloud architectures.

Learn:

- The definition and architecture of Terraform Modules
- Root Modules vs Child Modules hierarchy
- Passing dynamic inputs into child modules via `variable` blocks
- Extracting data from child modules via `output` blocks
- Structuring modular directories (`modules/`)
- Executing `terraform get` to pull modules into the `.terraform` cache
- State file nomenclature for module-based resources

Practice:

- Implementing The definition and architecture of Terraform Modules in local environment
- Implementing Root Modules vs Child Modules hierarchy in local environment
- Implementing Passing dynamic inputs into child modules via `variable` blocks in local environment
- Implementing Extracting data from child modules via `output` blocks in local environment
- Implementing Structuring modular directories (`modules/`) in local environment
- Implementing Executing `terraform get` to pull modules into the `.terraform` cache in local environment
- Implementing State file nomenclature for module-based resources in local environment
- Engineering a reusable Security Group child module (`modules/security_group`)
- Invoking the child module multiple times from the root `main.tf`
- Executing `terraform get` and analyzing the `terraform plan` output
